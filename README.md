# Epstein Files Card Game

An educational trivia card game based on publicly available data from the U.S. Department of Justice Epstein Files releases (Jan 2026) and prior court document unsealing (Jan 2024).

## ⚠️ Disclaimer

Appearance in these documents does NOT imply criminal conduct or wrongdoing. This is an educational/trivia game only.

## Features

- **Card Game**: Pick cards with the fewest mentions to take less damage
- **Solo & Multiplayer**: 1-4 players
- **Trivia Quiz**: 6 researched questions about the Epstein files
- **Animated Events**: Different animations based on your pick quality
- **Library**: Browse all 45 individuals and their mention counts

## Tech Stack

- React 18
- Vite
- HTML5 Canvas (fire particle effects)
- SVG animations

## Deploy

```bash
npm install
npm run build
```

Deployed on Vercel.
